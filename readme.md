# Vericampus

## Technologies utilisées

Le projet Vericampus repose sur les technologies suivantes :

- **Back-end : FastAPI** — framework Python utilisé pour créer les services et les API qui permettent à l'application de communiquer avec les données.
- **Front-end : React.js** — bibliothèque JavaScript utilisée pour construire l'interface visible et interactive de l'application.
- **Système de gestion de base de données (SGBD) : MySQL** — outil utilisé pour enregistrer et organiser les informations de manière structurée.
- **Cache : Redis** — système de stockage rapide utilisé pour conserver temporairement certaines données et accélérer les réponses de l'application.
