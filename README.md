# Briocampus

## Présentation

Briocampus est une plateforme de vérification des diplômes. Elle met en relation les ressources humaines et les universités afin de consulter directement les informations universitaires fiables.

## Fonctionnalités communes

Ces fonctionnalités sont disponibles pour les utilisateurs autorisés :

- connexion et authentification ;
- réinitialisation du mot de passe ;
- envoi et vérification d'un code OTP par e-mail ;
- gestion des paramètres du compte ;
- consultation des journaux d'activité.

## Fonctionnalités par rôle

### Administrateur

- gérer les rôles : créer, consulter, modifier et supprimer ;
- gérer les utilisateurs : créer, consulter, modifier et supprimer ;
- gérer les journaux : consulter, archiver automatiquement des copies, puis supprimer les anciens journaux selon une règle de conservation ;
- gérer les catégories de tickets : créer, consulter, modifier et supprimer ;
- gérer les universités : créer, consulter et supprimer.

### Ressources humaines (RH)

- acheter et consulter le solde de tickets de recherche ;
- rechercher le profil d'un diplômé à partir des informations disponibles ;
- enregistrer automatiquement une recherche lorsqu'un profil est trouvé ;
- gérer les profils utilisateurs : créer, consulter, modifier et supprimer ;
- consulter les statistiques suivantes :
  - nombre de tickets restants ;
  - nombre de profils consultés.

### Université

- mettre à jour le profil de l'université ;
- importer le palmarès des diplômés avec les informations suivantes : matricule étudiant, nom complet, faculté et date d'obtention du diplôme ;
- consulter les statistiques suivantes :
  - nombre de RH ayant consulté le palmarès de l'université ;
  - nombre total d'étudiants diplômés.
